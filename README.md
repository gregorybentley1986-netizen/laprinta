# laprinta.ru — каталог

Сайт-каталог изделий из пластика и термополиуретана, изготовленных методом аддитивных технологий. Витрина: разделы и подразделы, фильтры, карточка товара с фото, видео и 3D-моделью (GLB), избранное и корзина со спецификацией заказа в PDF (без оформления и оплаты), статьи. Админка для каталога, товаров и статей — `/admin`.

Стек: Next.js 15 (App Router) · React 19 · TypeScript · `@dnd-kit` (перетаскивание в админке) · `@google/model-viewer` (3D) · `pdfkit` (спецификация PDF) · TipTap (редактор статей) · `sanitize-html`. Данные — JSON-файл, медиа — локальная папка; внешняя БД не нужна.

## Запуск

Нужен Node.js 20.9+.

```bash
npm install
npm run dev          # http://localhost:3000
```

При первом запуске `npm run dev` / `npm run build` сам создаёт демо-каталог (9 поплавков, 7 разделов, 3 статьи) в `storage/`, если его ещё нет. Если каталог уже есть, но в нём ещё нет статей (данные созданы до появления раздела), добавляются только демо-статьи — товары и разделы не трогаются.

Админка: http://localhost:3000/admin. В режиме разработки пароль по умолчанию — `laprinta`. Для продакшена задайте пароль в `.env.local` (пример — `.env.example`):

```bash
ADMIN_PASSWORD=надёжный-пароль
ADMIN_SESSION_SECRET=длинная-случайная-строка   # необязательно, по умолчанию = пароль
```

Без `ADMIN_PASSWORD` в продакшене вход в админку закрыт.

Продакшен:

```bash
npm run build && npm run start
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер (создаёт демо-данные, если их нет) |
| `npm run build` / `npm run start` | сборка и запуск продакшена |
| `npm run seed` | **сбросить** каталог к демо-данным (удаляет всё, что сделано в админке) |
| `npm run seed:articles` | добавить / обновить демо-статьи, остальные данные и свои статьи не трогаются |
| `npm run seed:fetch` | заново скачать фото с Wikimedia Commons, пересобрать видео и `CREDITS.md` (нужны интернет и `ffmpeg`) |
| `npm run seed:glb` | пересобрать демо-модели GLB в `seed/media/models` |
| `npm run typecheck` | проверка TypeScript |

## Админка

- **Товары** (`/admin/products`): все товары сгруппированы по разделам. Строку можно перетащить за ручку — внутри раздела меняется порядок на витрине, на другой раздел (в группе или в дереве слева) — товар переносится. Цена и статус (опубликован / скоро / черновик) меняются прямо в списке и сохраняются сразу. Поиск по названию и артикулу.
- **Карточка товара**: название, адрес (slug, генерируется транслитом), артикул, описания, раздел, цена («от …», «по запросу»), наличие, грузоподъёмность, материал, расцветки, таблица характеристик, ссылки на Ozon / Wildberries, SEO.
- **Медиа**: загрузка перетаскиванием — фото (JPG/PNG/WebP до 8 МБ), видео (MP4/WebM до 100 МБ), 3D (GLB до 20 МБ; STL не принимается). Порядок — перетаскиванием, выбор обложки, подписи (alt), постер для видео и 3D.
- **Разделы** (`/admin/sections`): два уровня (раздел → подраздел), создание, редактирование, скрытие с сайта, порядок перетаскиванием. Раздел с подразделами или товарами удалить нельзя — сначала перенесите содержимое.

## Статьи

- Публично: список `/articles` (обложка, заголовок, анонс, дата, время чтения) и страница `/articles/<slug>` с датой, временем чтения, обложкой, текстом, блоком «Товары из статьи» и «Ещё статьи». Ссылка «Статьи» — в шапке, мобильном меню и подвале. Для каждой статьи — `<title>`, description, canonical, Open Graph (`article`, обложка) и JSON-LD `Article`.
- На сайте видны статьи со статусом «Опубликована» и датой публикации не позже сегодняшней (по Москве) — так можно запланировать выход. Черновики и будущие статьи отдают 404.
- Админка `/admin/articles`: список с порядком перетаскиванием и сменой статуса прямо в строке; карточка статьи — заголовок, адрес (slug), анонс, статус, дата, обложка (загрузить или взять из текста) с alt, связанные товары (до 8), SEO.
- Редактор (TipTap): абзац / H2–H4 / блок кода, жирный, курсив, подчёркнутый, зачёркнутый, код, ссылки, списки, цитата, разделитель, выравнивание, отмена/повтор.
  - **Таблицы**: вставка 3×3 со строкой-заголовком, добавление/удаление строк и столбцов, переключение строки-заголовка, объединение/разделение ячеек. На мобильных таблица прокручивается по горизонтали.
  - **Медиа**: фото (несколько файлов сразу — галерея), видео MP4/WebM, видео по ссылке YouTube / VK Видео / Rutube, 3D-модель GLB (`model-viewer`). У каждого блока — подпись, у фото — alt. Файлы лежат в `storage/uploads/articles/<id>/` и удаляются вместе со статьёй.
- HTML чистится `sanitize-html` по белому списку при сохранении и ещё раз при выводе (`lib/sanitize.ts`): только разрешённые теги и классы, медиа — только из `/media/`, iframe — только канонические адреса плееров YouTube (nocookie), VK и Rutube, ссылки — `https:`, `mailto:`, `tel:` и относительные.

## Корзина и спецификация PDF

- Кнопка «В корзину» есть на карточках каталога и на странице товара; счётчик — в шапке рядом с избранным. Корзина и данные покупателя хранятся в `localStorage` браузера, сервер их не сохраняет.
- `/cart`: количество (−/+ или ввод), удаление, очистка, необязательные поля (имя, телефон, e-mail, компания, комментарий).
- Итог — сумма фиксированных цен. Для позиций «от …» берётся минимальная цена, «Цена по запросу» в сумму не входит — в обоих случаях показывается пометка, что итог предварительный.
- «Скачать спецификацию (PDF)» отправляет `POST /api/spec` (`{ items: [{ id, qty }], customer }`). Сервер берёт названия, артикулы и цены из каталога (а не из браузера) и собирает A4 PDF через `pdfkit` (`lib/spec-pdf.ts`): шапка с логотипом, номер вида `LP-ГГММДД-XXXX` и дата, данные заказчика, таблица с миниатюрами, итог, контакты. Шрифты Raleway встроены (`assets/fonts/`), кириллица и ₽ поддерживаются. Номер спецификации не хранится — это идентификатор документа для переписки.

## Данные и медиа

- `storage/db.json` — каталог (разделы, товары, статьи). Запись атомарная, последовательная.
- `storage/uploads/` — загруженные файлы, отдаются по `/media/...` (с поддержкой Range для видео).
- Папку можно вынести: `DATA_DIR=/var/lib/laprinta`. Её нужно бэкапить и не терять при деплое; `storage/` не в git.
- Демо-материалы лежат в `seed/` (описание каталога — `seed/catalog.mjs`, статьи — `seed/articles.mjs`, фото — `seed/photos.json`). Источники и лицензии фото — в [`CREDITS.md`](./CREDITS.md).

## Дизайн-система

Все токены — в [`app/styles/tokens.css`](./app/styles/tokens.css): цвета, шкала шрифтов, отступы (шаг 4px), радиусы, тени, анимации, высота шапки, ширина сайдбара.

- Фон каталога чёрный, заголовки — бирюзовые; белый — только у карточек товара.
- Акцент `#00e8ef`. Логотип `la` белым + `printa` бирюзовым, шрифт Arista Pro — **только** для словесного знака.
- Заголовки — Raleway, текст — IBM Plex Sans.
- Шапка, подвал и боковая навигация каталога — общие компоненты в `components/site/`, поэтому оформление одинаково на всех страницах. На главной в шапке нет логотипа: его роль играет hero.
- Hero главной перенесён из утверждённого макета `design-drafts/homepage-forge.html`: неоновый фон фермы, постоянное свечение треугольника и курсорный прожектор; на мобильных — тег и словесный знак сверху, треугольник в центре, текст и кнопка снизу.
- Сетка адаптивная, проверена на 1440 и 390 px.

## Структура

```
app/
  (home)/           главная
  (site)/           каталог, товар, избранное, корзина, статьи, о компании, контакты
  admin/            вход, товары, разделы, статьи (редактор — admin/(panel)/articles/editor), server actions
  api/admin/upload  загрузка медиа товаров
  api/admin/article-upload  загрузка медиа статей
  api/spec          генерация спецификации PDF
  media/[...path]   выдача загруженных файлов
  styles/           tokens.css, base.css, site.css, cart.css, articles.css, admin.css
components/site/    шапка, подвал, навигация, карточки, галерея, hero, корзина, статьи
assets/fonts/       статические Raleway для PDF
lib/                типы, хранилище, каталог (дерево, фильтры), статьи, очистка HTML, видео-ссылки, авторизация
scripts/            seed, генерация GLB, загрузка фото
seed/               демо-каталог и медиа
design-drafts/      утверждённые HTML-макеты
```
