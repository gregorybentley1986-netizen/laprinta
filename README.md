# laprinta.ru — каталог

Сайт-каталог изделий из пластика и термополиуретана, изготовленных методом аддитивных технологий. Витрина без корзины: разделы и подразделы, фильтры, карточка товара с фото, видео и 3D-моделью (GLB), избранное. Админка для каталога и товаров — `/admin`.

Стек: Next.js 15 (App Router) · React 19 · TypeScript · `@dnd-kit` (перетаскивание в админке) · `@google/model-viewer` (3D). Данные — JSON-файл, медиа — локальная папка; внешняя БД не нужна.

## Запуск

Нужен Node.js 20.9+.

```bash
npm install
npm run dev          # http://localhost:3000
```

При первом запуске `npm run dev` / `npm run build` сам создаёт демо-каталог (9 поплавков, 7 разделов) в `storage/`, если его ещё нет.

Админка: http://localhost:3000/admin. В режиме разработки пароль по умолчанию — `laprinta`. Для продакшена задайте пароль в `.env.local` (пример — `.env.example`):

```bash
ADMIN_PASSWORD=надёжный-пароль
ADMIN_SESSION_SECRET=длинная-случайная-строка   # необязательно, по умолчанию = пароль
```

Без `ADMIN_PASSWORD` в продакшене вход в админку закрыт.

Продакшен:

```bash
npm run build && npm run start
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер (создаёт демо-данные, если их нет) |
| `npm run build` / `npm run start` | сборка и запуск продакшена |
| `npm run seed` | **сбросить** каталог к демо-данным (удаляет всё, что сделано в админке) |
| `npm run seed:fetch` | заново скачать фото с Wikimedia Commons, пересобрать видео и `CREDITS.md` (нужны интернет и `ffmpeg`) |
| `npm run seed:glb` | пересобрать демо-модели GLB в `seed/media/models` |
| `npm run typecheck` | проверка TypeScript |

## Админка

- **Товары** (`/admin/products`): все товары сгруппированы по разделам. Строку можно перетащить за ручку — внутри раздела меняется порядок на витрине, на другой раздел (в группе или в дереве слева) — товар переносится. Цена и статус (опубликован / скоро / черновик) меняются прямо в списке и сохраняются сразу. Поиск по названию и артикулу.
- **Карточка товара**: название, адрес (slug, генерируется транслитом), артикул, описания, раздел, цена («от …», «по запросу»), наличие, грузоподъёмность, материал, расцветки, таблица характеристик, ссылки на Ozon / Wildberries, SEO.
- **Медиа**: загрузка перетаскиванием — фото (JPG/PNG/WebP до 8 МБ), видео (MP4/WebM до 100 МБ), 3D (GLB до 20 МБ; STL не принимается). Порядок — перетаскиванием, выбор обложки, подписи (alt), постер для видео и 3D.
- **Разделы** (`/admin/sections`): два уровня (раздел → подраздел), создание, редактирование, скрытие с сайта, порядок перетаскиванием. Раздел с подразделами или товарами удалить нельзя — сначала перенесите содержимое.

## Данные и медиа

- `storage/db.json` — каталог (разделы, товары). Запись атомарная, последовательная.
- `storage/uploads/` — загруженные файлы, отдаются по `/media/...` (с поддержкой Range для видео).
- Папку можно вынести: `DATA_DIR=/var/lib/laprinta`. Её нужно бэкапить и не терять при деплое; `storage/` не в git.
- Демо-материалы лежат в `seed/` (описание каталога — `seed/catalog.mjs`, фото — `seed/photos.json`). Источники и лицензии фото — в [`CREDITS.md`](./CREDITS.md).

## Дизайн-система

Все токены — в [`app/styles/tokens.css`](./app/styles/tokens.css): цвета, шкала шрифтов, отступы (шаг 4px), радиусы, тени, анимации, высота шапки, ширина сайдбара.

- Фон каталога чёрный, заголовки — бирюзовые; белый — только у карточек товара.
- Акцент `#00e8ef`. Логотип `la` белым + `printa` бирюзовым, шрифт Arista Pro — **только** для словесного знака.
- Заголовки — Raleway, текст — IBM Plex Sans.
- Шапка, подвал и боковая навигация каталога — общие компоненты в `components/site/`, поэтому оформление одинаково на всех страницах. На главной в шапке нет логотипа: его роль играет hero.
- Hero главной перенесён из утверждённого макета `design-drafts/homepage-forge.html`: неоновый фон фермы, постоянное свечение треугольника и курсорный прожектор; на мобильных — тег и словесный знак сверху, треугольник в центре, текст и кнопка снизу.
- Сетка адаптивная, проверена на 1440 и 390 px.

```
  (home)/           главная
  (site)/           каталог, товар, избранное, о компании, контакты

  api/admin/upload  загрузка медиа
  media/[...path]   выдача загруженных файлов
  styles/           tokens.css, base.css, site.css, admin.css
components/site/    шапка, подвал, навигация, карточки, галерея, hero
lib/                типы, хранилище, каталог (дерево, фильтры), авторизация
scripts/            seed, генерация GLB, загрузка фото
seed/               демо-каталог и медиа
design-drafts/      утверждённые HTML-макеты
```
